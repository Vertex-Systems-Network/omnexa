## Implemented contract

P03.10 now provides classification-safe, non-authorizing module health/state diagnostics on top of the retained P01 health/readiness foundation:

- stable module ID, version and lifecycle health identity;
- deterministic `healthy`, `degraded`, `unavailable` and `failed` module-health states;
- required dependency missing/incompatible/lifecycle-unavailable conditions fail closed as unavailable rather than false healthy;
- optional dependency absence/incompatibility degrades only the affected module rather than globally failing boot;
- migration observation uses P03.09 migration identity/planning metadata without adding SQL execution authority;
- expected migrations with no observer, pending migrations, observation errors, inconsistency or failed migrations cannot report healthy;
- capability, permission and UI contribution summaries remain diagnostic counts only and create no grant/invocation authority;
- one module lifecycle/read failure does not suppress unrelated healthy-module reporting;
- aggregate module health projects to the retained P01 portable readiness vocabulary (`healthy`, `degraded`, `unready`) without reverse coupling;
- public diagnostic output remains bounded/classification-safe and does not emit credentials, secret values, raw tenant/org authority, internal stack traces or migration identifiers.

## Data / migration evidence

## Security / architecture boundary retained

- health is diagnostic evidence, never authorization or lifecycle command authority;
- required dependency failure remains fail-closed while optional absence degrades selectively;
- migration inconsistency cannot be represented as healthy;
- permission/capability/UI metadata remains non-granting;
- diagnostics remain secret-free and classification-safe;
- unrelated module failure remains isolated where feasible;
- P01 health/readiness remains the platform foundation and P03.09 remains migration-ownership authority;
- P03.11, P04+, business-feature, strategic X-program and AI/model/agent runtime were not introduced.
