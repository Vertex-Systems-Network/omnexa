## Delivered contract

The accepted P02.04 implementation provides only the governed human-user authentication and interactive-session lifecycle under `kernel.identity`:

- PBKDF2-HMAC-SHA256 password hashing with a governed 600,000-iteration work factor;
- no plaintext or reversible password persistence;
- disclosure-safe invalid-credential behavior;
- opaque access and refresh credentials, with only SHA-256 digests persisted;
- explicit access, refresh and absolute session expiry;
- deterministic refresh rotation, replay rejection and explicit revocation;
- password-change and account-lifecycle session invalidation;
- safe device/session inventory without secret material;
- tenant/organization context hints that remain non-authorizing and are reauthorized through a narrow dependency-inverted capability before relevant use;
- classification-safe authentication/session lifecycle audit hooks without secret payloads;
- additive `kernel.identity` v2 persistence migration.

Authentication remains identity proof only. No P02.05+ RBAC/policy, P02.07 MFA/passkeys, P02.08 service-account/API credentials, business permission/UI behavior, P03 runtime or AI/model/agent runtime was implemented.
