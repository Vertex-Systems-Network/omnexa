## Architecture

PR #50 is intended to keep storage as an infrastructure primitive below capability/domain boundaries. Object keys are infrastructure identity only and must not imply tenant authorization or business ownership. No P02+/AI/business runtime should be introduced by this package.

The implementation must remain compatible with future governed callers while future tenant, authorization, audit, classification, retention and AI semantics stay in their owning higher layers.

## AI-native compatibility

P01.06 must support the future path:

```text
AI -> governed capability -> owning domain -> storage
```

It must never establish:

```text
AI -> storage
```

No AI behavior is authorized or required in P01.06.
