- an authorized owner mutation and required canonical P04.01 event outbox enqueue commit or roll back together in the same local PostgreSQL transaction;

- relay publishes through P04.02;
- publication failure remains recoverable;

- producer-side published state never claims consumer/business exactly-once completion.
